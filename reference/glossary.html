课程术语预览

这是预先提供的课程用语表，帮助阅读。不是你的已掌握词库。实际掌握后的精炼定义才进入根目录 GLOSSARY.md。

术语本课程工作定义
Agent本课程指由模型依据环境反馈选择后续行动、由运行时执行并约束这些行动的系统。业界定义并不唯一。
LLM / 模型给定输入上下文产生输出的模型；不能仅凭输出文字认定外部动作已发生。
Agent loop / 执行循环反复调用模型、校验动作、执行工具并回传结果的控制过程。
Harness / 运行支撑让模型持续工作的程序与环境机制，包括循环、上下文、工具、状态、权限和反馈；不是一个统一协议。
Runtime / 运行时实际执行任务并管理生命周期的系统，与 Harness 含义有重叠，具体边界由实现约定。
Tool / 工具通过明确契约提供信息或执行动作的程序能力。
Tool call / 工具请求模型输出的工具名称与参数等结构化请求；它本身不是执行回执。
Context / 上下文本次调用实际提供给模型的信息；区别于服务器保存的全部状态。
Context engineering / 上下文工程在每一步选择、组织、压缩或外置输入信息的工程工作。
Compaction / 上下文压缩将已有上下文转换成更紧凑的表示；可能损失细节，应保留可重新读取的证据。
Token模型分词器使用的输入输出单位；字符数不是精确 token 数。
Structured output / 结构化输出按指定结构生成的结果；结构符合要求不保证事实正确。
Retrieval / 检索从外部资料找出候选信息；其权限、相关性和时效需要单独检查。
RAG / 检索增强生成结合检索材料产生回答的方法；可由固定代码或 Agent 决策驱动。
Agentic retrieval / 自主检索由模型根据当前证据决定查什么、何时继续查以及何时停止的检索过程。
Embedding / 向量表示把内容编码为数值向量，用于相似性检索等任务；相似不等于正确。
Memory / 记忆跨调用或任务保留、选择性读取的信息机制，需要来源、权限、时效与删除策略。
Skill / 技能包包含描述、任务指令和可选脚本/资料的可复用目录；不自动授予权限。
Progressive disclosure / 渐进式加载先提供少量描述，确定需要时再读取详细指令、工具定义或资料。
MCP连接应用与外部工具/上下文的协议；具体交互取决于协商/支持的协议版本。
Subagent / 子 Agent被委派有边界任务、通常拥有独立上下文的执行单元；是否共享存储由系统决定。
HITL / 人工介入程序在明确状态下等待人检查、选择或批准，再依规则继续。
Checkpoint / 检查点为恢复执行保存的状态与进度；它不自动撤销外部副作用。
Idempotency / 幂等同一逻辑操作重复提交不会产生额外的业务效果；实现需明确作用范围。
Trace / 执行轨迹由可观察事件组成的任务记录，包括模型/工具请求、结果、状态与耗时；不要求暴露模型隐藏思维。
Eval / 评估用定义好的任务、环境与评分规则测量系统表现。
Grader / 评分器评价结果某个维度的代码、模型或人工规则。
Prompt injection / 提示注入不可信内容试图改变应用预期行为或获取超出授权的动作。
Sandbox / 沙箱限制执行环境可访问的资源与行为的隔离机制；具体保证取决于配置。
Workflow / 固定工作流由预定义程序路径组织步骤的实现；本课只用作控制权和选型的对照。

定义依据：AI SDK 的模型/工具/循环说明、上下文工程、Agent 评估、Skills 规范和MCP 架构。这是教师为课程整理的简明工作定义，出现不同厂商叫法时以具体文档为准。
