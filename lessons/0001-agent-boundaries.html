01 · 模型调用基础 · LESSON 0001

谁决定下一步，谁执行动作？

把一个研发助手拆成模型决策、程序执行和环境反馈，解释 Agent 与一次问答的边界。

阅读与检查 15–20 分钟动手任务 20 分钟资料核对 2026-09-22

这一课的具体成果

画出一次“查组件文档再回答”的四步轨迹，并标出每一步由谁负责。

前置知识：能读懂 TypeScript 对象、函数调用和 async/await；不需要 LLM API 经验。

从你熟悉的前端边界开始

在前端里，用户点击按钮只是意图；事件处理函数检查条件，再调用接口。模型提出“读取 Button 文档”也只是一个动作请求。真正访问文档的是宿主程序里的工具实现。把模型输出直接当成已经发生的事实，就像看到按钮文案“已保存”便认为数据库一定写入成功。

本课程的研发知识助手使用虚构的组件文档和工单。用户问“Button 为什么不能重复点击”，模型可以直接生成回答，也可以先请求读取文档。只有后者实际返回了具体版本的说明，程序才获得可核验的新信息。说得像事实与取得事实，是两种事件。

先认清三个角色

模型接收本轮输入，提出下一步或生成回答；工具是具有明确输入输出的程序能力；执行循环把工具结果交回下一轮，并决定是否允许继续。AI SDK 的当前 Agent 概述也用模型、工具和循环来描述这个组合。这里的“决定”指生成供程序处理的动作，并不代表模型拥有系统权限。

你要开发的应用负责把三个角色接起来：提供哪些工具、怎样验证参数、执行结果怎样记录、超过预算怎样停止。模型可能推断出好策略，但这些可执行约束需要由应用落实。后面的 Harness 一词，主要帮助我们讨论承载这些职责的运行支撑。

观察下一步从哪里来

固定按“读取文档 → 摘要 → 返回”执行，是代码预设的流程。读取文档后，模型发现版本缺失，自主决定再查发布记录，这是由反馈改变下一步的 Agent 行为。两者都可能使用大模型；调用几次 API 不是分类标准。面对已知、简单任务，用固定流程也完全合理。

本课只需识别控制权。一次模型调用也可能服务于一个更大的 Agent；反过来，多轮聊天如果没有可执行工具和环境反馈，也不能仅凭轮数证明它具备完成外部任务的能力。阅读旧文章时，把定义差异记下来，避免把某个营销名称当成统一技术规范。

把过程放进 TypeScript

以下是我们自定义的 TypeScript 教学类型，表示动作请求，不是任何供应商协议。片段用于阅读，尚未接入模型。

type ModelDecision =
  | { kind: "readDoc"; docId: string }
  | { kind: "answer"; text: string };

const request: ModelDecision = {
  kind: "readDoc",
  docId: "button-v2",
};

// 宿主执行后，才得到环境反馈：
const observation = {
  docId: "button-v2",
  text: "loading 为 true 时阻止重复点击。",
};

// 下一轮的模型输入可以包含 observation。
// request 本身不代表 readDoc 已成功执行。

轨迹是“用户提出问题 → 模型请求 readDoc → 宿主执行并返回 observation → 模型依据结果回答”。验证一次工具是否成功，应检查执行结果；单看模型产生了请求还不够。

动手：给执行轨迹标注负责人

  1. 用四行写出上述轨迹，为每行标注“用户 / 模型 / 宿主”。
  2. 插入一个失败分支：文档不存在时，宿主返回什么，模型下一轮应该依据什么再决定？
  3. 另写一个固定流程版本，圈出它与模型驱动版本在“选择下一步”上的区别。
验收条件

你能区分动作请求与执行结果；失败分支不写成成功；能说明决定下一步与执行动作可以属于不同角色。

做过以后，再看参考答案

参考轨迹：用户发问；模型提出 readDoc(button-v2)；宿主查找并返回文档或 NOT_FOUND；模型根据已有结果回答，或者请求可用的其他文档。固定流程的下一步由代码写死，模型驱动流程则把工具结果作为下一轮决策依据。无论哪一种，权限检查仍属于执行程序。

停下来，从记忆里回答

模型输出了 readDoc 请求，此刻哪个判断成立？

答案与理由

应选“动作仍待执行”。模型负责产生请求；宿主还要完成参数检查、执行和结果记录。

换个需求，还能用吗？

把场景换成“帮我关闭工单”。模型回复“已关闭”之前，最少还缺哪类证据？

迁移题参考要点

需要工单系统实际处理该动作的结果，并核对目标工单与成功状态。只读文档的例子没有授权你写工单；写操作还要有对应权限与必要确认。本题先识别证据边界，审批机制会在后续专课展开。
